# SCLABS-195 – Działanie checkboxa „Customer data privacy” – TC pozytywny

## Informacje podstawowe

- **ID przypadku testowego:** SCLABS-195
- **Plan testów:** TP-01 – Rejestracja i logowanie
- **Typ:** Test Case
- **Priorytet:** Medium
- **Status:** Otwarty

## Opis

Sprawdzenie widoczności checkboxa „Customer data privacy” oraz możliwości jego zaznaczenia i odznaczenia.

## Warunki wstępne

- Użytkownik nie jest zalogowany w sklepie.
- Strona sklepu My Store jest dostępna.
- Formularz rejestracji nowego użytkownika jest otwarty.

## Kroki testowe

| Krok | Akcja | Dane wejściowe | Oczekiwany rezultat |
|---|---|---|---|
| 1 | Sprawdź widoczność checkboxa „Customer data privacy”. | Odszukaj checkbox „Customer data privacy” w formularzu rejestracji. | Checkbox „Customer data privacy” jest widoczny w formularzu. |
| 2 | Sprawdź możliwość zaznaczenia checkboxa „Customer data privacy”. | Kliknij checkbox „Customer data privacy”. | Checkbox zostaje zaznaczony. |
| 3 | Sprawdź możliwość odznaczenia checkboxa „Customer data privacy”. | Kliknij ponownie zaznaczony checkbox „Customer data privacy”. | Checkbox zostaje odznaczony. |

## Wynik wykonania

Test nie został jeszcze wykonany. Wszystkie kroki mają status „To do” w Jira.
