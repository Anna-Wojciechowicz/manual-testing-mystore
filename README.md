# manual-testing-mystore

**Manual testing portfolio – MyStore e-commerce application**

## O projekcie

Projekt przedstawia dokumentację testów manualnych sklepu internetowego MyStore. Został przygotowany w ramach rozwijania umiejętności w zakresie testowania oprogramowania i stanowi część mojego portfolio testera manualnego.

## Cel projektu

- Praktyczne zastosowanie wiedzy zdobytej podczas kursu testowania manualnego.
- Przygotowywanie i dokumentowanie przypadków testowych.
- Weryfikacja poprawności działania funkcjonalności aplikacji.
- Ćwiczenie analizy wymagań oraz projektowania testów.

## Testowana aplikacja

**MyStore – sklep internetowy**

Aplikacja demonstracyjna wykorzystana do przygotowania i dokumentowania przypadków testowych.

- **Adres:** https://dev-mystore-testlab.coderslab.pl/index.php

- **GitHub** – dokumentowanie projektu i prezentacja portfolio.
